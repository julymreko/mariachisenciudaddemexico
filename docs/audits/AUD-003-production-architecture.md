## Finding AUD-003-F01 — HTTP does not redirect to HTTPS

Plesk reports:

`Permanent SEO-safe 301 redirect from HTTP to HTTPS: On`

However, the effective Apache port 80 vhost has the HTTPS redirect rules commented and does not define the production DocumentRoot.

Observed rules:

`#RewriteEngine On`
`#RewriteCond %{HTTPS} off`
`#RewriteRule ^ https://%{HTTP_HOST}%{REQUEST_URI} [R=301,L,QSA]`

As a result, HTTP requests fall through to Apache's main default document root and return the Plesk default page with 200 OK.

This is a current production behavior and an SEO/migration risk. It is documented only; no correction was made during AUD-003.
